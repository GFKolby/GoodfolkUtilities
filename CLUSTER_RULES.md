# Goodfolk Toolbox Cluster Rules

Goodfolk should grow through topic clusters, not isolated pages.

A topic cluster is a group of related tools and guides that help users understand and solve a specific problem.

## Cluster structure

A strong cluster should include:

1. One primary tool
2. Three to six supporting guides
3. Internal links between all related pages
4. A clear CTA from each guide to the primary tool
5. Related guide links on each article
6. Related reading links from the primary tool back to the guides

Electricity cluster:

Primary tool:

- `/blog/average-electric-bill-by-home-size`
- `/blog/how-many-kwh-does-a-house-use-per-day`

## Cluster rules

Every guide in a cluster should:

- Link to the primary tool.
- Link to related guides in the same cluster.
- Use natural anchor text.
- Avoid repeating the exact same paragraph across every page.
- Add a helpful next step.

Every primary tool in a cluster should:

- Link to the most relevant supporting guides.
- Include a short explanation of the topic.
- Include FAQ if useful.
- Include related tools if useful.

## When to create a new cluster

Create or expand a cluster when:

- Search Console shows impressions for the tool or related queries.
- A page has clicks or rising impressions.
- Multiple related queries appear around the same topic.
- The topic connects naturally to an existing Goodfolk tool.
- The cluster can support at least three useful guides.

Do not create a cluster just because the topic sounds interesting.
