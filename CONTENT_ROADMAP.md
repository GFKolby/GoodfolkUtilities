# Goodfolk Toolbox Content Roadmap

This roadmap is used to guide agent-assisted content and tool creation.

The goal is to prioritize work based on Search Console traction, useful topic clusters, and practical value to users.

## Current phase

Phase: Agent-assisted cluster growth

Primary objective:

Build strong topic clusters around tools that are already receiving impressions or clicks.

Do not build random new tools unless they support an active or promising cluster.

## Weekly operating cadence

Once per week:

1. Review Search Console pages.
2. Review Search Console queries.
3. Identify pages gaining impressions.
4. Identify queries without dedicated pages.
5. Choose the next cluster task batch.
6. Create agent tasks or GitHub issues.
7. Let Codex implement.
8. Review PRs.
9. Merge and deploy.
10. Request indexing for important new URLs.
